# ProCam
Kotlin + Jetpack Compose + CameraX camera app for photographers and videographers.

**Photo:** manual ISO / shutter / focus distance, EV, white-balance presets, tap-to-focus, pinch zoom, 4:3 / 16:9,
timer, 5-shot burst, flash, rule-of-thirds grid, spirit level, live histogram, vendor Night / HDR / Portrait / Retouch (device dependent).
**Video:** 480p–4K, stabilization, pause/resume, torch, manual controls.
**Smart:** face detection + auto-focus on face, smile shutter, QR/URL scanner, exposure warnings (clipping / too dark).

Saved to Pictures/ProCam and Movies/ProCam.

## APK
Push to GitHub (`main`) → Actions → **Build APK** → download artifact **ProCam-debug-apk**.
